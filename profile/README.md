# miPlug

A Helsinki-based studio building AI-native web products, configurators and website migrations.
We work with an AI-first stack and ship fast, from prototype to production.

### Products

- **[Sitejump](https://sitejump.dev)** – Website migration to Lovable, without losing your rankings.
- **JEMAA** – AI audio platform for stories, audiobooks and podcasts.
- **Happens** – Multilingual event discovery powered by AI agent crawlers.
- **Dlemma** – Social platform for sharing and voting on everyday dilemmas.
- **PanicBuddy** – Privacy-first, offline stress-management app.

### Services

- Website migrations to Lovable from WordPress, Drupal and Shopify, with SEO and GEO preserved
- 3D and B2B product configurators
- AI-powered web apps, from idea to launch

### Stack

Lovable · Claude · TypeScript · React · Supabase · Vercel
